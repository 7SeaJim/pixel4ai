## zhihu-san-er-dither-strip

| 项 | 内容 |
| --- | --- |
| 作者 | 知乎 @三二（图片水印） |
| 获取方式 | 用户于 2026-09-10 在对话中提供的截图，960×320 PNG |
| 本地原图 | `refs/dither/sources/zhihu-san-er-dither-strip.png`（不进版本库） |
| 派生文件 | `ramps/reference-strip.pxl`（92×10 格）、`previews/reference-strip.png` |
| 还原方法 | 原图渐变条位于 (30,100)–(949,199)，每格 10px；取每格中心点颜色，归并为 4 种真实颜色（黑、深灰、浅灰蓝、白）。原图有 13 格压缩杂色，已并入最近的真实颜色 |
| 还原校验 | 把 `.pxl` 按每格 10px 渲染，与原图该区域逐像素比对，差值大于 40 的像素为 0 |
| 用途 | 个人学习参考。项目如果公开发布，需要确认是否取得作者许可，或者移除派生文件 |
